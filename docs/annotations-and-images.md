# 批注与图片编辑架构

## 数据归属与段落定位

批注线程归属于笔记，文末隐藏区 `feishu-lite-comments:v2` 按行保存线程 JSON，每个线程保存唯一 ID、创建和更新时间、open/resolved 状态、初次选中的原文 `excerpt`、当前锚点和多条消息。重新关联只修改当前锚点，初次原文保持不变。插件设置保存功能开关和显示名，正文和批注数据跟随 Markdown 文件进行 Git 同步。

普通段落末尾使用 `%%fl-block:<uuid>%%` 标识，多个线程可以共享段落 ID。ATX 标题的标识位于紧接标题的独立隐藏行，标题文字和 Obsidian 的章节链接保持原样。定位先寻找段落 ID，再在段落里查找引用原文；引用文字变化时退回整段定位。缺少 ID 时通过原文和前后文进行保守恢复，多个候选或重复 ID 显示待关联，由用户选择新位置。frontmatter、围栏/缩进代码、表格、HTML、数学块和隐藏记录属于保护区域，单次批注选区需要处于同一段落。

百分号在 JSON 中编码为 Unicode 转义，消息包含 `%%` 时仍保持隐藏区完整。解析器兼容旧版 v1，遇到未知版本、重复存储区/线程 ID、损坏 JSON、Git 冲突和非文末存储区时拒绝写回，保留原文件。Git 承担文件同步；多端同时编辑同一线程仍需要解决文件冲突。

## 读写与跨笔记迁移

`note-edit.ts` 优先使用打开的编辑器缓冲区，再读取磁盘。编辑器修改采用公共前后缀裁剪后的单次 replaceRange，保留撤销能力；磁盘修改采用 Vault.process。弹窗确认时验证快照或重新定位当前对象，存在并发变化时提示重新操作。

跨笔记移动迁移完整线程。用户可以关联目标已有段落，也可以在目标追加原文摘录，来源笔记的正文保留。两文件写入前，`.feishu-lite/operations/<id>.json` 持久化迁移前后快照，依次更新目标和来源并将打开的缓冲区刷新到磁盘，完成后移除日志。恢复命令幂等重放旧/新快照，遇到并发修改、笔记改名或缺失时保留日志。日志含完整快照，应随私有 Vault 管理。

## 图片排版与边缘缩放

图片宽度使用 Obsidian 原生 Wiki/Markdown 嵌入语法。每次嵌入紧邻 `%%fl-image:<JSON>%%` 保存 v1 元数据，包括稳定 ID、图注和可选 left/center/right 对齐方式。同一附件多次嵌入时，各处可以独立排版。已有 ID 按唯一 ID 定位，尚未分配 ID 的引用按原始片段和上下文校验，歧义时提示重新点击。

选择图片后，鼠标悬停时显示四角和两侧拖拽柄，拖动时显示边框，静止时无常驻边框。手势阶段更新当前 DOM 宽度，保持原图比例，结束时把最终像素宽度写回一次笔记事务；Escape、pointercancel、关闭工具条或渲染节点消失时取消预览。居中图片的边缘位移按中心锚定计算，宽度受可用栏宽及 10000px 上限约束。方向键支持 10px 微调，Shift 支持 1px 微调。阅读视图和 Live Preview 共用当前嵌入的布局逻辑，原生分栏的拉伸样式会尊重显式宽度。

图文并排使用原生 callout，首行图片、空引用行之后为完整 Markdown 文字：

```markdown
> [!img-text-left]
> ![[截图.png|320]]
>
> **这一步的说明**
>
> - 关键调用
> - 需要确认的地方
```

`img-text-left/right` 表示图片位于哪一侧，桌面为图片 40% 与文字 60% 的双栏，600px 以下自动上下排列。文字可在原生编辑器中编辑，0.2.3 的简化界面保留已有图文块的数据与渲染兼容。切换左右和恢复上下排列保留文字、图注、尺寸和元数据，其他图片应放在图文块外。转换需要图片独占一行，已有多图分栏可先取消分栏。渲染时图片和文字分别包装为独立容器，原 Markdown 源码保持可读。

## 图片编辑与原图生命周期

图片编辑生成新的 PNG，以及同目录的 `<output>.fl-edit.json`。项目包含版本、库内原图路径、原始尺寸和修改时间、裁剪矩形、按顺序绘制的箭头/方框/画笔/文字矢量标注。再次编辑从原图与项目重建，当前会话提供撤销/重做、移动/删除标注、重置和取消裁剪。恢复原图替换当前嵌入，保留其排版和图注。

预览使用缩小的位图，所有手势换算到原始像素坐标，导出使用原图分辨率。静态 PNG/JPEG/WebP/BMP/AVIF 可以编辑，网络图、SVG/GIF 可以查看和排版；编辑需要导入静态图片。安全预算为 3200 万像素、单边 16384px、500 条标注，项目中的路径、尺寸、裁剪与坐标均进行校验。

取消编辑不写附件。保存先生成图片与项目，再核验当前引用并替换；关联失败时保留已保存附件并提示路径。通过 Obsidian 重命名编辑结果时，同步迁移 sidecar；重命名原图或所在文件夹时更新项目原图路径。附件清理把项目原图视为引用，遇到损坏项目时暂停本次清理。

## 模块边界与界面

| 模块 | 职责 |
| --- | --- |
| comment-core.ts | 可移植存储、段落锚点、线程操作、迁移计划、Markdown 导出 |
| comments.ts | 命令、CodeMirror 装饰、阅读标记、桌面侧栏和手机底部弹层 |
| image-core.ts | 嵌入解析与唯一定位、尺寸/对齐/图注、分栏及图文块变换、项目与几何校验 |
| image-tools.ts | 渲染上下文、图片工具条、边缘拖拽、项目保存与路径维护 |
| image-editor.ts | 原图加载、触摸/鼠标画布、矢量标注、历史记录和 PNG 导出 |
| note-edit.ts | 当前笔记安全读写、编辑器事务、持久化迁移和恢复 |
| dialogs.ts | 可访问的输入、确认、笔记及选项弹窗、异步错误反馈 |

批注包含新建、回复、编辑/删除消息、解决/重新打开、搜索与状态筛选、跳回原文、重新关联、跨笔记移动和导出。Live Preview 隐藏定位与存储标记，源码模式保留可检查的文本。阅读视图能确定引用位置时高亮原文，其余提供段落标记。原生 callout 渲染范围为空时通过其 CodeMirror 宿主定位，重复图片或文字仍要求唯一候选。所有用户内容通过文本节点显示。
